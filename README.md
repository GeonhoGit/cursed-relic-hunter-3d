# 저주받은 유물 사냥꾼 · 3D FPS

기존 게임0.13의 탐험·전투 규칙을 옮긴 3D 1인칭 실행판입니다. Three.js로 방·몬스터·가구·무기를 입체적으로 그립니다. 평면 던전에서 약1m 높이로 점프할 수 있습니다. 계단·복층은 없습니다. 모델은 유적 분위기에 맞춘 절차적 입체 아트입니다.

## 실행

### 모델 원본 보관

캐릭터·보스 15종과 투사체 16종의 Blender 검토본을 [art/README.md](art/README.md)에 정리했습니다. 새 캐릭터·투사체는 아직 게임에 적용하지 않았으며, 현재 실행판은 기존 표시 코드를 사용합니다. 현재 사용하는 무기 4종의 GLB는 `public/models/weapons/`에 있습니다.

### 홈페이지 배포

`npm run build`로 타입 검사 후 상대 경로의 웹 실행판을 만듭니다. `dist/`의 내용을 홈페이지 저장소 `GeonhoGit.github.io`의 `play/프로젝트 B/`에 복사하고, 기존 `FILES.md`를 새 파일에 맞게 갱신합니다. 모델 원본과 제작 스크립트는 이 원본 저장소에서 관리합니다.

Node.js22.12 이상과 WebGL2를 지원하는 PC 브라우저를 사용합니다. 이 폴더에서 실행하세요.

```powershell
npm install
npm run dev
```

[3D 게임 열기](http://127.0.0.1:5199/)

```powershell
npm test              # 게임 규칙과 FPS 판정
npm run build         # 타입 검사와 독립 배포 파일 dist 생성
npm run test:pages    # 프로젝트 B 경로에서 모델 로딩·저장·설정 유지 검사
npx playwright install chromium
npm run test:browser  # 실제 3D 화면과 조작 검사
npm run preview       # 빌드한 게임 실행
```
