# 저주받은 유물 사냥꾼 · 3D FPS

기존 게임0.13의 탐험·전투 규칙을 옮긴 3D 1인칭 실행판입니다. Three.js로 방·몬스터·가구·무기를 입체적으로 그립니다. 평면 던전에서 약1m 높이로 점프할 수 있습니다. 계단·복층은 없습니다. 모델은 유적 분위기에 맞춘 절차적 입체 아트입니다.

## 실행

Node.js22.12 이상과 WebGL2를 지원하는 PC 브라우저를 사용합니다. 이 폴더에서 실행하세요.

```powershell
npm install
npm run dev
```

[3D 게임 열기](http://127.0.0.1:5199/)

```powershell
npm test              # 게임 규칙과 FPS 판정
npm run build         # 타입 검사와 독립 배포 파일 dist 생성
npx playwright install chromium
npm run test:browser  # 실제 3D 화면과 조작 검사
npm run preview       # 빌드한 게임 실행
```

지역 번호가 없는 기존 저장은 기존 단일 지역 결말을 유지합니다. 지역 번호가 있는 탐험은 사제 처치 기록을 이어 세 번째 지역으로 이동할 수 있습니다. 지역2는 재의 사제·봉인술사·사슬 사냥개·독서 석상, 지역3는 궤도 감시자·심장 수호병·균열 주술사·공허 기사와 기존 적을 섞은 구성입니다. 일반 적12종까지 추가했으며, 남은 유물·영구 목표와 다중 웨이브 확장은 아직 포함하지 않습니다.

## 유물 등급과 등장 확률 · 2026-10-05

유물 후보 **한 칸**을 생성할 때의 기본 등급 확률입니다. 유물방·무료 새로고침·상점의 일반 유물 진열대에 적용합니다.

| 일반 | 55% | 회색 | 잿불 심지, 서리 결정, 응급 붕대, 도약의 장화, 붉은 숫돌, 결사의 송곳니, 정밀 손목띠, 돌가죽 부적 |

등급 안에서는 획득 가능한 유물을 균등하게 뽑습니다. 보유·소모·상실한 유물과 해금 전 유물을 제외하고, 선택지는 중복 없이 하나씩 추첨합니다. 남은 후보가 없는 등급은 제외해 나머지 확률을 비례 조정합니다. 새로고침은 기존처럼 새로운 후보를 우선합니다. 저주 유물은 일반 유물 추첨에서 제외되며 제단의 고정 선택 또는 상점의 별도 저주 진열대로 등장합니다. 회복약은 일반 등급의 고정 판매 상품입니다.

선택창·보유 목록·상점에 색상과 등급 배지를 표시하며, **유물 등급과 등장 확률**을 펼쳐 규칙을 확인할 수 있습니다. 등급은 기존 성능·가격을 변경하지 않고, 이미 저장된 선택지와 상품은 유지합니다. 검증: 신규14개 포함 단위611개, 타입 검사·빌드, Chromium10개가 통과했습니다. 6만 회 추첨의 등급/등급 내 비율과 실제 방·상점 생성, 저장 호환·재접속·새로고침·작은 창 가독성을 확인했습니다. 사용자 마우스·창 포커스를 조작하지 않았습니다.
