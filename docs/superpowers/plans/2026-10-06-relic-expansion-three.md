# 유물 확장 3차 실행 계획

사용자의 다음 단계 실행 요청에 따라 원본 v1.4의 R31/R32를 추가한다. 현재37종에서39종으로 늘리며 지도 정보·보상 재추첨의 기존 흐름을 확장한다. 이전1·2차 미커밋 작업과 현재 서버/감도/저장 기록을 보존한다.

## 구현 계약

- R31 길잡이 등불(일반): 현재 방과 연결된 미방문 방의 종류를 지도와 문 표시에 공개한다. 기본 지도는 방문한 방의 종류와 발견한 연결만 표시한다. 방문 플래그·길 생성·문 잠금·충돌·실제 방 종류는 바꾸지 않는다. 소유/상실 직후 표시를 갱신한다.
- R32 운명의 주사위(희귀): 획득 때 탐험 전체 추가 재추첨2회를 받는다. 상자마다 기존 무료1회를 먼저 사용하고, 이후 주사위를 쓴다. 다른 상자·다음 지역에서도 잔량을 공유한다. 후보 교체가 불가능하거나 제단/선택 완료/잘못된 방에서는 상태·RNG·잔량을 바꾸지 않는다.
- 새로고침 결과와 무료/주사위 사용 기록·잔량·RNG는 기존 순차 저장을 통해 함께 저장한다. 상실 시 사용할 수 없으며 잔량/이력은 보존해 재획득으로 초기화하지 않는다.
- G07: 서로 다른 유물24종 실제 획득으로5P와 R32 해금. 기존 획득 기록을 사용하며 출발 시 해금을 복사한다. 현재 탐험 풀은 갱신하지 않는다. 기존 R30은 다시 잠그지 않는다.
- 현재 등급55/30/12/3, 상자 선택 직후 탐험, 일반 보상3개·제단2개·상점4칸, 60 투자 상한과 구형 저장은 유지한다.
