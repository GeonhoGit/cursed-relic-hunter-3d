# 허수아비 인형(R18) 구현 계획

승인된 미구현 유물 설계와 사용자의 다음 단계 승인에 따라 R18을 완결한다. 43→44종이며 기존 미커밋 작업·사용자 저장·조작 설정을 보존한다. 현재 실행 중인 사용자 브라우저의 OS 포인터/창 포커스는 조작하지 않는다.

## 계약과 판단

- 희귀 보조. G04 사슬의 사제 첫 처치 후 다음 출발부터 해금. 이미 기록된 첫 처치도 인정하며 현재 탐험의 해금 스냅샷은 변경하지 않는다. 목표9개/최대45P/투자 상한60 유지.
- 최대100u의 안전한 지상 위치에 HP30·300틱 미끼1개 설치, 성공만720틱 ID별 충전/성공 사용 기록. 실패는 ID/RNG/재사용/목표 이력 미소비와 안내. 벽·가구·함정·출구·몸체·출현 예약 겹침을 거부한다.
- 일반 적의 새 목표 선택은 미끼를 우선한다. 기존 고정 공격과 보스 목표/패턴은 유지한다. 아군은 미끼를 공격하지 않는다. 미끼가 없어지면 진행 중 대상 공격은 기존 대상 소실 처리로 복귀한다.
- Ruling: 미끼는 적 배열의 가짜 몬스터가 아닌 별도 유효 NPC 대상이다 — 원래 적10명/방 클리어/처치/금화/회복 보상에 영향을 주지 않기 위해. 기존 AI·실제 근접/범위/돌진/탄환·보스 우발 피해를 재사용한다.
- Ruling: 몸체 반경7u·높이44u의 고정 지상 설치물로 이동 충돌에 참여한다 — 설치물 통과를 피하면서 적 접촉 반경20u로 공격 가능. 탄환은 실제 몸체 높이/벽 엄폐를 검사하고 플레이어/아군 공격은 미끼에 무해하다. 사슬 당김으로 위치를 이동시키지 않는다.
- 전환 아군과 동시 존재 가능. 일반 적/보스 실제 공격은 미끼를 파괴할 수 있으나 보스 목표는 플레이어다. 미끼 수명은 동결/시간 정지와 독립적인 시뮬레이션 시간이며 시간의 빚은 충전만 멈춘다.
- 만료/파괴/상실/방 이동/전투 종료/보스 단계/최종 사망은 활성 미끼를 제거한다. 교체·상실·이어하기는 충전을 초기화하지 않는다. 저장은 기존 schema1/contentprototype-0.13의 선택 필드로 보존하고 손상 상태/ID 충돌/잘못된 수명·충전/위치를 거부한다.
- 모형·이름·체력 막대·남은 수명·충전 HUD와 실패 안내를 추가한다. 낮은 품질·640×480·반복 GPU 회수·실제 획득/사용/재접속을 검증한다. 새 의존성/원격 푸시는 없다.
