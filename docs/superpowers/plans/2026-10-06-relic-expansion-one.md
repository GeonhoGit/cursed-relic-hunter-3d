# 유물 확장 1차 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved plan inline. Run one fresh-context review after integration.

**Goal:** 승인된 R09/R14/R19/R21/R22/R29 여섯 유물을 실제 전투·보상·표시·저장에 연결한다. 총 유물은 27→33종이다.
**Architecture:** 기존 사격·적중·피격·클리어 훅과 공통 피해/지형 판정을 재사용한다. 새 전투 효과와 생존 효과를 작은 순수 모듈로 분리하고 저장 타입은 선택 필드로 확장한다.
**Tech Stack:** TypeScript, Three.js, Vitest, headless Playwright, IndexedDB.
**Spec:** 사용자 승인한 2026-10-06 대화 계획, 원본 v1.4 §5~7, ../specs/2026-10-05-remaining-relics-design.md 중 해당 6종.

## Global Constraints

- 기존 피해·무기·유물·저장 호환·60Hz 전투를 보존한다. 새 의존성을 추가하지 않는다.
- 등급 가중치 55/30/12/3, 중복 획득 방지, 무료 상자 재추첨 1회를 유지한다.
- 사용자 OS 마우스와 포커스를 조작하지 않는다. 브라우저 검사는 headless와 마우스 잠금 금지로 실행한다.
- 이번에는 여섯 유물만 구현한다. 새 아군·포털·잠금방·정예 시스템과 다른 유물은 후속이다.

## Review Focus

- 산탄/귀환/분열/반사로 추가 피해가 재귀 발동하거나 같은 적을 중복 공격하지 않아야 한다.
- 벽·수직 조준·방패·보스 무적·단계 전환에서 판정과 표시가 일치해야 한다.
- 피격 무적/회피로 막힌 상태는 정화 재사용 시간을 소비하지 않아야 한다.
- 방 재방문/재접속/지역 이동으로 이끼 진행이나 유물 재사용 시간이 초기화되지 않아야 한다.
- 구 저장을 읽고 새 저장의 손상된 시간·해금·효과 좌표를 거부해야 한다.
