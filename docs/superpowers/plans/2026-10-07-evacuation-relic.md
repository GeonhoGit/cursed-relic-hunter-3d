# 대피의 깃털(R24) 구현 계획

승인된 남은 유물 확장의 다음 단계로 실제 생존 피격에서 작동하는 R24를 완결한다. 46→47종이며 기존 미커밋 작업/저장/서버/조작 설정을 보존한다. 실행 계획·테스트 우선 흐름으로 진행하며 사용자 OS 포인터/창 포커스를 조작하지 않는다.

## 계약과 판단

- 영웅 패시브, 별도 해금 없이 기존 상자/새로고침/상점 등급 추첨에 포함한다. 실제 받은 피해가 양수이고 최종적으로 살아 있으며 R24를 보유한 경우80~120u(3.2~4.8m)의 안전한 땅으로 순간 대피, 실제 방당 성공1회.
- 피해/피격 무적/약화·둔화/정화/응급 붕대·왕의 계약·가시 왕관 처리는 먼저 유지한다. 피해 취소/회복/추가 무적은 없다. 최종 사망·소유 상실·무적/회피로 피해를 받지 않은 경우는 발동하지 않는다. 한 틱은 기존 최고 피해1회만 적용한다.
- Ruling: 후보는 가까운 적 반대 방향부터120/100/80u와32개 방향을 결정적으로 검사한다 — 실패/선택에서 RNG를 소비하지 않아 저장 후 같은 진행을 보존한다. 벽/가구/동적 설치물과 경계를 제외하고 기존 닻의 안전 목적지 검사를 재사용한다. 함정은 휴지 중에도 제외한다. 구덩이는 후속 지형 단계에서 같은 검사에 연결한다.
- Ruling: 자동 대피는 같은 방의 가리지 않은 안전 위치를 고른다 — 지상 몸체의 벽/설치물 시야를 추가 검사해 모르는 벽 뒤로 강제 이동하지 않는다. 적 점유·폭탄 범위·출현/순간이동 예약을 제외한다. 후보가 없으면 위치/방당 기회/ID/RNG를 소비하지 않고 원래 피격만 유지한다.
- 순간이동은 공통 위치 변경을 사용해 점프/회피·가시 경로를 끝내고 현재 teleportTick을 기록한다. 화면은 중간 경로로 보간하지 않으며 출발/도착 표시와 HUD로 발동 및 이 방의 잔량을 알린다. 닻은 그대로 유지하고 보조 성공 사용으로 세지 않는다.
- maze 방의featherUsed와 legacy의featherRooms로 영구 방당 기록을 저장한다. 보스 단계/전투 종료/재방문/유물 상실/부활/이어하기로 기회가 리필되지 않는다. 새 방/새 지역/새 탐험은 새 기록을 사용한다.
- 기존schema1/contentprototype-0.13 선택 필드·등급55/30/12/3·목표9/45P·투자60 유지. 잘못된 소유/방/지역/중복·불리언/순간이동 틱·발동 cue를 거부하고 구형 없는 저장은 유지한다. 새로운 의존성/커밋/원격 푸시는 없다.
