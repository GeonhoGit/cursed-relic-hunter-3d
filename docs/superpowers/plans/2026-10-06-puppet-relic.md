# 아군 전환 유물 · 꼭두각시 실

승인된 미구현 유물 확장의 다음 단계로 R17을 완결한다. 기존40종에서41종으로 늘리고 이전 미커밋 작업·서버·사용자 저장을 보존한다.

## 계약

- 영웅 보조, G03 문지기 첫 처치 후 다음 출발부터 해금. 기존 R16 해금도 유지하고 현재 탐험의 스냅샷을 바꾸지 않는다.
- 유효 조준점100u 이내의 가까운 일반 적1명을240틱 아군으로 전환. 거리 동률은ID순, 실제 HP/원래 ID/개체 자리 유지. 보스·출현 보호·사망·기존 아군·벽 너머는 제외한다. 성공만840틱 ID별 재사용, 대상 없음/이미1명/잘못된 단계는 ID/RNG/재사용 미소비와 실패 안내.
- 원래 AI·공격 예고/재사용·몸체/탄환/엄폐를 재사용하며 아군은 적만 공격한다. 일반 적은 새 목표를 플레이어/아군 중 가까운 대상으로 고르고 이미 고정된 공격은 대상 ID를 유지한다. 보스는 플레이어를 계속 목표로 삼되 실제 범위/탄환은 아군에도 피해를 준다.
- 플레이어/아군 공격은 아군에 무해. 아군 탄환의 소속은 생성 시 고정하고 플레이어 탄환 유물을 상속하지 않는다. 적의 직접/탄환/범위 피해를 받되 플레이어 약화/둔화/피격 무적은 상속하지 않는다. 아군 피해는 플레이어 약화와 독립적이다.
- 균열 주술사 아군은 증원 없이 피해8·속도110·42틱 예고/144틱 재사용 단발을 사용한다. 변환 전 소환 예약은 취소하되 소비된 시도와 이미 생성된 들쥐의 적 소속을 유지한다.
- 240틱 종료/유물 상실/보스 단계 정리 시 살아 있는 원래 적은 적대로 복귀하고 정상 방은 아군만 남아도 클리어되지 않는다. 실제 사망은 원래 개체의 처치1회, 보스 최종 클리어는 잔여 개체 cleanup 예외를 유지한다. 원래 적10명 예산에서 전환1명은 같은 슬롯을 계속 점유한다.
- 장착/상실/지역 이동/이어하기는 재사용을 초기화하지 않는다. UI/일시정지 시간은 진행하지 않는다. 전환 수명은 시뮬레이션 시간이며 동결/적 시간 정지로 늘리지 않는다.
- 실제 성공한 보조 사용 ID만 탐험/프로필에 선택적으로 기록해 다음 G08 단계의 근거를 만든다. 과거 보유 사실로 사용을 추정하지 않으며 R33/R34/G08 보상은 해당 후속 단계에서 추가한다.
- 기존 모델에 색/표식/시간·HP 안내, 아군 탄환 구분과 대상에 맞는 위협 표시를 추가한다. 낮은 품질·640×480·GPU 회수·저장 결정성과 손상 검증을 확인한다.
