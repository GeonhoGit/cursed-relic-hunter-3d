# 이동 유물 · 유랑자의 닻(R26)과 거미 발톱(R27)

승인된 미구현 유물 설계의 다음 구현으로 두 이동 유물을 완결한다. 현재44→46종이며 기존 변경/저장/서버/조작 설정을 보존한다. 실행 계획·테스트 우선 흐름으로 수행하고 사용자 OS 포인터/창 포커스는 조작하지 않는다.

## 계약과 판단

- 두 유물은 희귀, G05 유물 심장 첫 처치 후 다음 출발 스냅샷으로 해금한다. 기존 승리 이력 인정, 현재 풀 불변. 목표9/최대45P/투자60 유지.
- R26 보조는 현재 안전한 땅에 동시1개 닻을 설치하고 다시 우클릭하면 같은 방의 위치로 귀환한다. 성공 귀환만600틱 재사용. 설치/귀환 성공은 보조 사용 기록으로 세며 실패는ID/RNG/충전/기록 미소비다. 설치/상실/교체/이어하기로 충전을 초기화하지 않는다.
- Ruling: 닻은 몸체 충돌이 없는 바닥 표식이다 — 이후 설치벽/적/위험 지형이 점유할 수 있으며 귀환 시 다시 검증해야 한다. 현재 지상·경계/정적물체/가구/동적벽·경고/활성 함정·살아 있는 몸체·폭탄/출현 예약을 검사한다. 휴지 중 함정은 현재 안전하지만 경고/활성으로 바뀌면 귀환을 거부한다.
- Ruling: 같은 방의 순간 귀환은 중간 벽을 지나며 경로 피해를 받지 않는다 — 목적지만 검사하고 이전 위치와 연결된 접촉/함정/광선/가시 경로 및 작은 거리의 화면 보간을 만들지 않는다. 귀환은 점프/진행 중 회피를 끝내되 체력·충전·기존 무적을 추가하거나 초기화하지 않는다.
- Ruling: 닻 수명은 현재 방이다 — 같은 방의 일반 전투 종료/보스 단계에서 보존하고 방/지역 이동·유물 상실·최종 사망에서 제거한다. 안전한 교체는 설치물 유지. 구덩이 지원은 후속R28 단계에서 같은 목적지 검증에 연결하며 이름만 있는 구덩이 상태를 추가하지 않는다.
- R27 패시브는 회피의 실제 벽 접촉에서 현재 이동 입력의 접선 방향으로 최대40u 연장 이동한다. 회피당 성공1회이며 접선 입력이 없는 정면 충돌·벽에 닿지 않음·가구/미끼 접촉은 발동하지 않는다. 다른 벽/닫힌 문/경계를 통과하지 않고 기존 회피 시간/무적/충전/반격 방향을 연장하지 않는다.
- Ruling: 충돌면과 입력으로 축을 정하고 일반 이동 sweep을 재사용한다 — 코너/두 축 접촉은 이동 가능한 접선을 고르고 완전히 막힌 시도는 소비하지 않는다. R15 가시는 실제 접촉점과 연장 끝점으로 한 회피의 연속 경로를 기록해 코너를 가로지르는 가시를 만들지 않는다.
- 닻 위치/소유 방·지역/귀환 충전과 회피당 사용/순간이동 틱은 기존schema1/contentprototype-0.13 선택 필드로 보존한다. 변조/중복ID/잘못된 소유·충전/교차방/유물 이력/활성 회피 관계를 검증하고 구형 없는 필드는 그대로 인정한다.
- 설치 표식·귀환 안내/거리·10초 충전과 발톱 준비/사용 상태를 표시한다. 실제 획득/조작/저장/재접속·640×480·낮은 품질/GPU 회수·기존 전투/점프/회피/가시/반격을 검증한다. 새 의존성/커밋/푸시 없음.
