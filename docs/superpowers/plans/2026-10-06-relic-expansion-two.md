# 유물 확장 2차 실행 계획

사용자가 다음 계획의 실행을 요청했다. 기존 전투 흐름을 확장하는 R06/R10/R15/R23을 추가해33→37종으로 늘린다. 원본 v1.4와 remaining-relics-design의 해당 네 항목을 따른다. 이전1차의 미커밋 변경을 보존하며 같은 로컬 게임에서 진행한다.

## 구현 계약

- R06 궤도 나침반(희귀): 실제 기본 발사4회마다 피해0.5D의 보조탄1개. 반경26u에서21틱 공전, 방출 시점 조준/높이 방향으로 속도320·수명60틱 발사. 기본 발사 지연 없음. 생성 효과·상태·귀환은 상속하지 않고 도탄/관통/유도만 사용한다. 생성탄 예산120에 공전부터 포함, 예산이 차면 추가탄만 생략한다.
- R10 중력 파편(영웅): 기본탄 적중 위치의 반경64u·90틱 구체1개, 일반 적을50u/s로 당김. 벽 뒤·동결/시간정지 적·보스 이동 제외. 전역300틱과 발사당1회, R09와 독립. 피해 없음.
- R15 가시 장화(희귀): 실제 회피 경로에120틱 가시, 대상별30틱마다 피해4, 동시2구간. 새 구간 생성 불가 시 기존 구간 수명 유지. G02 누적 최초 일반 전투방5회로 다음 출발부터 해금.
- R23 가시 왕관(일반): 실제 생존 피격 뒤 반경60u에 피해12, 전역60틱. 무적/회피·체력 구매·자기 비용에서는 발동하지 않으며 벽 뒤/보스 보호를 따른다. 부활 후 최종 생존·보유 상태에서 최대1회.
- 생성된 피해는 당시 성장/약화 수치를 저장하고 새 효과의 피해로 다른 생성 효과를 다시 만들지 않는다. 방 종료/이동/단계 전환에서 설치 효과를 정리하고 쿨다운·발사 누적은 유지한다.
- 가시의 폭은12u, 바닥 근처의 적에게만 닿는다. 겹친 두 구간의 같은 대상은 공통30틱 간격을 공유한다.

## 기록

- 시작 기준:1차 완료721단위·Chromium14·타입/빌드 통과. HEAD ac4da05, 이전 작업의 미커밋 파일을 유지한다.
- 범위 판단: 새 아군/포털/낙하/지도 규칙과 탐험 편의 유물은 후속으로 두고, 이미 있는 전투 훅으로 네 유물의 완전한 경로를 만든다.
- 최초 행동 검사10개 중7개 실패를 구현 전 확인했다. 첫 저장 검사도 선택적 상태 미지원으로2개 실패한 뒤 검증 모듈을 연결했다.
- 겹친 가시는 대상별 공통30틱을 사용한다. 방/보스 단계의 효과 정리는 발사 누적과 쿨다운을 초기화하지 않는다. 공전탄의 벽 너머 위치가 막히면 플레이어 위치에서 방출한다.
- 단위38개 추가, 최종 전체759개(58파일) 및 타입 검사·빌드 통과. 500개 분산 시드의 상자/새로고침/상점 생성과 실제 선택/구매를 검사했다.
- 신규 Chromium2개 모두 통과: 카드 등급/선택/이어하기, 효과 위치/범위·낮은 품질·효과 감소·GPU 회수, 640×480의10개 상태 표시. 이전 G02 안내 문구 검사는 새 두 유물 해금 문구로 갱신했다.
- executing-plans의 마지막 fresh-context 리뷰를 relic_expansion_two_final_review에서 완료했다. 부활 상실 후 설치물·공전 예약 정리, 보스 가장자리 가시 판정, 인스턴스 GPU 버퍼 해제의3건을 실패 검사 후 수정했다. 독립 재검증에서 해당3건 모두 해결됐고 남은 조치 필요 결함은 없었다.
- 강제 당김 뒤에는 경로를 닫고, 부활 상실은 curses의 책임 지점에서 잃은 유물의 설치물만 즉시 정리한다. 이미 발사된 궤도탄과 재사용 시간은 유지한다. 활성 설치물은 저장에서도 현재 보유를 요구한다.
- 최종 관련 Chromium16개가1.2분에 전부 통과했다. GPU 검사에 두 InstancedMesh의 실제 dispose 이벤트도 포함했다. README·IMPLEMENTATION의37종/등급/동작/검증 기록을 갱신했다. 기존500KB 번들 경고는 유지된다.
