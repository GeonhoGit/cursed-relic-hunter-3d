# 3D FPS 구조 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 현재 게임의 동작과 저장 호환성을 유지하며 렌더링·저장·HUD의 책임을 분리한다.

**Architecture:** 기존 함수의 본문과 호출 순서를 보존한 모듈 추출이다. 기존 `World`, `SaveStore`, `validRun`, `Settings`, `SaveRecord`, `SCALE`의 공개 경로는 유지한다. HUD는 현재 전투 상태와 UI 상태를 인자로 받아 갱신하며 지도 캐시만 자체 소유한다.

**Tech Stack:** TypeScript, Three.js, IndexedDB, Vitest, Playwright.

**Spec:** 현재 동작과 저장 호환성은 `IMPLEMENTATION.md` 및 기존 테스트를 기준으로 한다. 이번 요청은 구조 변경이며 신규 기능이나 밸런스 조정은 포함하지 않는다.

## Global Constraints

- 작업 대상은 `유물 사냥꾼/3d fps`다.
- 마우스 포인터와 사용자 창 포커스를 조작하지 않는다.
- 게임 수치, 전투 판정, RNG 소비, 저장 형식/오류/대기열, DOM ID와 화면 문구를 보존한다.
- 의존성을 추가하지 않는다. 원본2D 프로젝트를 변경하지 않는다.
- Git 저장소가 없으므로 대상 파일의 임시 백업으로 변경 전 기준을 보관한다.

## Review Focus

- 기존 모듈 경로로 `validRun`, `Settings`, `SaveRecord`, `SCALE`을 가져오는 코드가 유지된다.
- 모델의 이름 있는 자식 객체는 전투 애니메이션과 동일하게 연결된다.
- 몬스터 재생성/방 이동 시 기존 재질·텍스처 회수 순서가 유지된다.
- 지도 캐시는 탐험 시드/지역/방/방문/전투 상태 변경에 반응한다.
- 저장 검증 분리로 런타임 순환 의존이나 이전 저장의 승인 범위 변화가 생기지 않는다.

## Task 1: 저장 검증과 저장소 분리

**Interfaces:** `save-types`는 `Settings`, `SaveRecord`, `defaultSettings`를 제공한다. `save-validation`은 `validRun(unknown): value is RunState`, `validRecord(unknown): value is SaveRecord`를 제공한다. `save.ts`는 기존 공개 경로를 재노출하며 저장 대기열과 IndexedDB만 소유한다.

- [x] 기존 전체 단위670개 및 빌드의 변경 전 통과를 확인한다.
- [x] 기존 타입과 검증 본문을 그대로 추출한다. 오류 클래스와 저장 트랜잭션은 유지한다.
- [x] 전체 단위 검사와 빌드를 실행한다. Expected: 실패0, 기존670개 통과.

- [x] 전체 단위 검사와 빌드를 실행한다. Expected: 실패0.
- [x] 기존 브라우저 검사로 모델과 방 렌더링, 탄환 및 GPU 회수를 확인한다.

## Task 3: 전투 HUD 분리

**Files:** `src/main.ts`, 새 `src/game/hud.ts`. 검증 중 확인한 기본 지형 fixture와 검사 시간 설정은 `tests/browser/fps.spec.ts`에서 정리한다.
**Interfaces:** `CombatHud.update(s, { modal, yaw, reducedMotion, mouseCaptured, noticeUntil })`, `CombatHud.resetMap()`. HUD는 지도 캐시와 DOM 갱신을 소유하고 main은 저장·메뉴·게임 루프를 유지한다. 새 탐험·이어하기·지역 이동의 명시적 캐시 초기화를 그대로 호출한다.

- [x] 기존 `updateHud`를 옮기고 전역 참조만 명시적 인자로 바꾼다.
- [x] main의 HUD 전용 import와 지도 캐시 변수를 제거하고 단일 `CombatHud`를 생성한다.
- [x] 전체 단위 검사·빌드·브라우저 검사를 실행한다. Expected: 실패0, 기존 문구/작은 창/재접속/지도/입력/모델 동작 유지.
- [x] 변경 전 백업과 대조해 본문/공개 경로 보존을 검토하고 구현 기록을 갱신한다.
