# 보상·상점 유물과 G08

중단된 R17 리뷰 수정 뒤 사용자가 요청한 다음 계획을 이어 R33 상인의 저울과 R34 빈 액자를 완결한다. R17 포함41종에서43종으로 늘린다. 이전 작업·사용자 저장·서버/조작 설정을 보존한다.

## 계약

- G08 서로 다른 보조 기술3종의 실제 성공 사용으로5P. 기존 선택 기록에서 이미 구현된 auxiliaryUsed만 사용하며 보유 사실로 사용을 추정하지 않는다. 9목표·현재 최대45P, 각 능력 투자 상한60 유지.
- R33(일반)/R34(영웅)는 G08 완료 후 다음 출발 스냅샷부터 후보·획득 가능. 현재 탐험 해금은 바꾸지 않는다.
- R33 현재 금화 가격20% 할인/소수 올림. 일반 유물24→20, 저주30→24, 회복약20→16. 화면/구매 가능/실제 차감이 같은 가격 함수를 사용한다. R33 자체 구매는 획득 직전 가격을 지불하며 이후 상품부터 할인된다. 상실 시 원래 가격 복구.
- R34 새 일반 보상 후보3→4. 이미 생성된 선택지 수는 유지하며 새로고침도 기존 선택지 수를 보존한다. 상실 후 기존4개는 유지하고 신규 보상은3개. 후보 중 선택하는 획득 수는1개, 제단2·상점4 고정/기존 무료1·주사위 추가2/중복 획득 방지 유지.
- 선택지 수·해금·이력·가격·잔량/RNG는 현재 저장 경로로 함께 보존. 구형3개 선택지와 이전 해금 스냅샷은 그대로 유효하며 변조4개는 R34 획득 이력 없이 허용하지 않는다.
- 넷째 후보와 할인 안내는640×480에서도 스크롤/선택 가능. 실제 획득·성장·거래·재접속·R17 수정·등급 회귀와 최종 리뷰를 수행한다.

- R17 수정: spawnTicks0 정상 전환과 hostile NPC 목표 공격의 player 피해 누락을 신규7개 RED로 확인한 뒤 원래 특수 공격의 상태를 복사한 player 충돌 조회로 해결. NPC 차지 가로채기를 별도 결과로 구분한다. 38개 R17 검사·전체856/61파일·타입/빌드 통과.
- Ruling: 기존 가격은 등급/지역에 무관한 종류별24/30/20이다 — 이 관례를 유지하고 할인만 적용한다.
- Ruling: 기존 후보가 부족한 경우 재추첨이 줄어든 길이를 기준으로 삼아도 현재 풀은 획득 중복 방지로 늘지 않는다 — 제공된 슬롯의 길이를 보존하고 가능한 후보만 채운다.
- Ruling: 미구현 R37의 체력 결제/신규 제외 조건은 해당 유물 단계에서 연결한다 — 현재 금화 거래에만 실제 효과를 구현하며 이름만 있는 카드를 추가하지 않는다.
